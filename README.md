# VLOO Product Prototypes

Static VLOO prototypes for product feature exploration and implementation handoff.

## Files

- `user-facing-flex-booking-calendar-prototype.html` - user booking page for Flexible Stay.
- `host-portal-flex-booking-calendar-prototype.html` - host capacity page for Flexible Stay availability.
- `host-portal-extended-stay-calendar-prototype.html` - separate host portal prototype for reviewing and approving Extended Stay requests.

## Feature Prototypes

- `space-tags/` - public space signal tags for object pages and listing cards.

## Notes

- Flexible Stay remains an upfront-payment day booking prototype with a 20 booking-day limit.
- Extended Stay is request based: request, host approval, capacity allocation, then payment setup.
- The host Extended Stay prototype shows how accepted recurring desks reduce potential Flexible Stay availability without rebuilding the Flexible Stay calendar.
- The prototype is standalone HTML/CSS/JavaScript and can be opened directly in a browser.
