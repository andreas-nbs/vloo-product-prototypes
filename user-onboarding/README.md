# VLOO user onboarding prototype

Open `index.html` in a browser. The prototype covers the four-step user privacy onboarding flow from the privacy specification:

1. Trust-building overview
2. Required service processing, displayed as information rather than consent controls
3. Optional preferences, all off by default
4. Profile visibility, with contact details hidden

The final action demonstrates saving preferences locally in the interface. It does not call a production API.
