# VLOO host privacy onboarding prototype

Interactive host onboarding aligned with sections 5 and 6 of the VLOO privacy specification.

- Required company, office, booking, payment, and payout processing is explained rather than presented as consent.
- Hosting insights, product news, and marketing permission default to off.
- Space discovery is visible by default and can be hidden.
- Contact sharing defaults to off.
- Host profile visibility defaults to on.
